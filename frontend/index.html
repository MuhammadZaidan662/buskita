Tentang Aplikasi

BusKita adalah aplikasi pencarian dan pemesanan tiket bus antarkota untuk UTS Struktur Data.

Status: terhubung ke backend C++. Array, struct, pointer, Selection Sort, dan Binary Search dijalankan oleh server C++. Halaman ini hanya menampilkan hasil JSON dari server, termasuk log sorting dan searching.
